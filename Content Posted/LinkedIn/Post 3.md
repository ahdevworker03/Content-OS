When I first started learning programming, I thought becoming good at coding was mostly about learning syntax and writing code faster.

But the more I learn, the more I realize that some of the most important skills in Computer Science are not only technical.

A few skills I believe every CS student should build besides coding:

• Problem Solving
Learning how to break problems into smaller parts and think logically instead of only searching for answers.

• Communication
Explaining ideas clearly, asking questions, collaborating with others, and writing understandable code.

• Independent Learning
Technology changes constantly, and learning how to learn on your own becomes extremely valuable over time.

• Consistency
Progress in tech usually comes from showing up regularly, building projects, making mistakes, and improving step by step.

I’m still working on all of these myself while continuing my journey in software engineering.
