As Computer Science students, we spend a lot of time talking about programming languages, frameworks, and projects.But one thing that often gets overlooked is the operating system we use every day.

When I first started learning programming, I viewed operating systems simply as a way to run applications. Windows, macOS, and Linux all seemed to do the same thing.

Over time, I realized they offer very different experiences and teach different lessons.

Windows is the operating system most students (and even people) start with. It has excellent software compatibility, a familiar interface, and a relatively low learning curve.

macOS is popular among developers because of its stability and its Unix-based foundation, which provides access to many tools commonly used in software development.

Linux, however, taught me something different.

As I spent more time using Linux, I found myself relying on the terminal, reading documentation more carefully, understanding how software is installed, and learning more about how the system actually works behind the scenes.

What makes Linux especially important for Computer Science students is that many real-world software environments are built around it. Linux powers a large portion of web servers, cloud infrastructure, containers, and other systems that modern applications depend on.

This does not mean every student should immediately abandon Windows or buy a new computer.

But I do think every CS student should spend some time learning Linux.
Not because it makes you a better programmer overnight.

But because it helps you better understand the environment where software runs, gets deployed, and serves real users.

Programming is not only about writing code.

It is also about understanding the systems that make that code work.
What operating system do you use for development, and has it changed the way you learn or work?
