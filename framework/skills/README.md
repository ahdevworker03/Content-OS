# Skills

## Purpose

Skills provide reusable expert consultation for the AI agent. Unlike workflow prompts, skills do not execute repository workflows or produce workflow artifacts. They support discussion, analysis, review, and decision-making around the Framework.

Skills are independent of the production pipeline and may be invoked whenever their expertise is needed.

---

## Available Skills

| Skill                  | Purpose                                                                                                 |
| ---------------------- | ------------------------------------------------------------------------------------------------------- |
| **Content Strategist** | Evaluates, challenges, and prioritizes content opportunities before they enter the production workflow. |
| **Content Reviewer**   | Reviews completed content for quality, framework compliance, and brand consistency before publication.  |

---

## Skills vs. Workflow Prompts

- **Skills** provide expert guidance and recommendations.
- **Workflow Prompts** execute a defined stage of the content production pipeline.

Skills help decide **what** should be created or improved.

Workflow prompts perform **how** the content is produced.
