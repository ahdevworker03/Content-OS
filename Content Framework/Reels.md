# Reels

Reels are short, fast glimpses into the learning process.
They should match the brand's realism and show the actual environment.

Reels are best for:

- Quick reflections
- Small technical insights
- Light project updates
- "Facepalm" hooks that drive curiosity

---

## 1) Quick Insights

### Purpose

Deliver one small thing I learned quickly.

### Style Rules

- **Environment Mandate:** At least one clip must be in a "student" setting (campus, messy desk, library).
- **Facepalm Hook:** Start with a mistake or struggle (e.g., "I spent 3 hours on this bug so you don't have to").
- **Visual Over Text:** Focus on showing the actual IDE, terminal window, or physical setup rather than just text on screen.

### Possible ideas

- One programming tip I found
- One Linux tip from my setup
- One Git trick I finally got
- One tool I'm using
- One beginner mistake I made
- One concept I finally understood in under a minute

---

## 2) Personal Reflection

### Purpose

Show my perspective in a short, unpolished format.

### What to do

- Share something I realized
- Talk about a mistake I made this week
- Share a thought about university/exam stress
- Show progress in my thinking

---

## 3) Project Clips

### Purpose

Show movement in the project in a short visual format.

### Content style

- Visual and Simple
- Focus on the IDE and terminal
- Show "Before" (Broken/Ugly) and "After" (Fixed/Better)
- Progress-oriented
