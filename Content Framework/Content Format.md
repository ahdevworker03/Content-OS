# Content Distribution Logic

This is not a strict rule.
It is a guide for balance based on the student-builder journey.

## Carousels (Deep Documentation)

Suggested balance:
- Educational (I learned X): 50%
- Education + Personal Opinion (Why I like X): 25%
- Project Thinking (How I solved X): 15%
- Project Documentation (What I built today): 10%

## Reels (Quick Insights)

Suggested balance:
- Quick Educational (Mistake/Tip): 50%
- Personal Reflection (Student life/Thinking): 30%
- Project Related (IDE/Terminal clips): 20%

## Stories (Daily Reality)

Suggested balance:
- Learning Journey (WIP Loops): 40%
- Behind the Scenes (Unpolished 20%): 25%
- Quick Value (Small tips): 20%
- Engagement (Low-friction polls): 10%
- Project Updates (Real wins): 5%

---

# Content Planning Logic (Trigger-First)

When choosing what to post, use this flow:

### Step 1: The Trigger
What happened today that was interesting, frustrating, or rewarding?

### Step 2: Choose the Format
- **Carousel:** Deep mastery/reflection.
- **Reel:** Quick tip/mistake.
- **Story:** Daily update/interaction.

### Step 3: The Goal
- Document learning.
- Build trust (show the struggle).
- Show progress.
- Start conversation (classmate level).

---

# What Makes a Strong Post in This Brand
- It uses **"I" over "You"** language.
- It includes a **Personal Trigger** (why it was posted).
- It feels **Grounded** (mentions exams, library, or messy code).
- It shows **Actual Progress** (code snippets/terminal).
- It is **Low-Friction** for the audience to interact with.
