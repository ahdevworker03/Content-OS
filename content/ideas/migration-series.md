## Idea 1 — Migration Series: Vanilla JS → TypeScript → React + TypeScript + Tailwind

- **Status:** Not started (teased in portfolio story sequence)
- **Working title:** How I Migrated My Portfolio from Vanilla JS to React + TypeScript + Tailwind
- **Core idea:** Break down the step-by-step migration of the portfolio across its stack evolution, what changed at each step, and what each migration taught.
- **Authentic trigger:** The real, already-done migration history of the creator's own portfolio (Vanilla JS → TypeScript → React + TypeScript + Tailwind), plus design/a11y/responsiveness/structure improvements.
- **Audience problem:** Students don't know how to evolve a simple project into a modern stack without rewriting it.
- **Expected audience value:** A practical, honest path for upgrading a beginner project to React + TypeScript, including the messiness and decisions along the way.
- **Suggested pillar:** Web development projects built/iterated in real time (Brand View).
- **Suggested primary format:** Carousel series (multiple parts).
- **Recommended platforms:** Instagram (Lebanese Arabic) + LinkedIn adaptation (English).
- **Rationale:** The portfolio story sequence teased it; content is real and deep enough for a series.
- **Confidence:** High
- **Notes for Content Planning:** Split into parts by migration step. Keep each part trigger-first and tied to the real code. Do not duplicate the existing "Why I Built a Portfolio" carousel — this is the "how it evolved" angle.
